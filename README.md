# Wordique — eBook Writing & Publishing Services Website

A modern, fully responsive single-page website for **Wordique**, a professional eBook ghostwriting, editing, cover design, and publishing services business. Built with vanilla HTML, CSS, and JavaScript — no frameworks, no build step.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

## ✨ Features

- **Animated preloader** — book page-flip animation with a progress bar
- **Custom cursor** with trailing effect and top scroll-progress bar
- **Sticky navbar** with mobile hamburger menu and smooth-scroll navigation
- **Hero section** — particle canvas, animated blobs, a 3D floating book cover, typewriter effect, and trust badges
- **Animated stat counters** (clients, books delivered, years, satisfaction)
- **Services grid** — 8 service cards with an interactive tilt effect
- **Portfolio marquee** — horizontally scrolling book covers
- **Process timeline** — animated 4-step workflow
- **Why Us** — feature list with an orbital achievement graphic
- **Testimonials carousel** — auto-sliding with dots and touch support
- **FAQ accordion** — 8 expandable questions
- **Contact section** — info column plus a validated form with a toast confirmation
- **Footer** with services/company links and a newsletter signup
- **Back-to-top button** and IntersectionObserver-based scroll animations throughout
- **Fully responsive** down to 640px

## 🛠️ Tech Stack

- **HTML5** — semantic single-page structure
- **CSS3** — custom properties (CSS variables), flexbox/grid, keyframe animations
- **Vanilla JavaScript** — all interactivity, IntersectionObserver scroll reveals, canvas particles
- **[Google Fonts](https://fonts.google.com/)** — Playfair Display + Inter
- **[Font Awesome 6.5](https://fontawesome.com/)** — icons

No frameworks, no bundlers, no dependencies to install.

Light violet (`#8B5CF6`) and sky blue (`#0EA5E9`) accents on a clean white background. Colors are driven by CSS custom properties for easy theming.

## 🚀 Getting Started

No installation or build tools required.

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/<your-repo>.git
   cd <your-repo>
   ```
2. Open `index.html` directly in your browser.

   Or serve it locally (recommended, for correct asset loading):
   ```bash
   # Python 3
   python -m http.server 8000
   ```
   Then visit `http://localhost:8000`.

## 🌐 Deployment

Because it's a static site, you can host it for free on:

- **GitHub Pages** — push the repo and enable Pages in the repository settings
- **Netlify** or **Vercel** — drag-and-drop or connect the repo (no build command needed)
